# Global AGENTS.md

## ファイルパスの取扱い

ここはWSL環境です。Windowsのパスが指定された場合、WSLのパスに変換してからファイル読み込みしてください (e.g: `C:\Users\nico\Pictures\image.png` -> `/mnt/c/Users/nico/Pictures/image.png`)

## Git Rule

- Gitを使う際、`-C` オプションは利用禁止
- コミットメッセージは、他に指示がなければConventional Commitsに沿って日本語で記述する

## Tools

- Clipboard: クリップボードにコピーする場合、`clip` コマンド(e.g: `echo "hello" | clip`) を使用すること。`clip.exe`の直接利用は禁止
- jq: JSONの解析は必ず`jq`を使うこと。Pythonの`json`モジュールや`python3 -c`でのJSON処理は使用禁止
- rg: grepやfindの代わりに`rg`を推奨

## 人間による音声入力

プロンプトは音声入力（改行のない連続した口語の文章）するときがあり、誤字脱字が発生します。文脈から判断できる範囲は適切に補完・推測してもよいです。作業前に意図や用語の確認が必要な場合、必ずユーザーに確認するようにしてください

## Markdown形式のルール

- 水平線 `---` の多用は禁止。セクションは原則として見出しで区切ること。長文で1～2回使用するのはOK
- 過度に構造化せず、3階層以内の見出しに抑える
- 見出しを太字にしたり、記号での装飾は禁止

## 実装方針

- 局所最適ではなく、全体最適を目指す。必要であれば仕様や設計も含めて見直す
- バグ修正は、短期的な解決でなく長期的な問題解決を優先する
- 過剰設計やオーバーエンジニアリングには注意し、シンプルな実装を優先する
- ソースコード内にはコメントを過剰に記載しない
